// 03 — open source

Open source

Two small, production-grade systems across Go, NestJS, Next.js and Node + React. Each is tested against real PostgreSQL and real browsers in CI.

System 01

Ledger platform

ledger-consoleNext.js→ ledgerdGoledger-nestNestJS→ PostgreSQL

One API contract with two interchangeable backends. CI runs both on the same database and proves a transfer created in Go replays correctly through NestJS, and runs the console's browser tests against each.

GoCI passing

ledgerd

Double-entry ledger service: the core under wallets, payouts and invoicing.

  • Idempotent transfers: concurrent retries with one key move money exactly once
  • Deadlock-free row locking, stress-tested with 32 goroutines × 1,280 transfers
  • Invariants enforced in the database too: deferred balance trigger, append-only journal
  • Go
  • PostgreSQL
  • Concurrency
View on GitHub ↗
NestJSCI passing

ledger-nest

The same ledger, written the NestJS way, as a drop-in replacement for the Go service.

  • Dynamic modules, DI lifecycle hooks, DTO validation and generated OpenAPI at /docs
  • Custom @IdempotencyKey() decorator, replay interceptor, guard with @Public() metadata
  • Request fingerprint matches Go byte for byte; interop job proves it in CI
  • NestJS
  • TypeScript
  • OpenAPI

ledger-console

Operator console that runs on either backend.

  • Cache Components: prerendered shell with live data streamed into <Suspense>
  • Server Actions with updateTag read-your-own-writes; double-submit safe by design
  • Streaming CSV route handler; Playwright suite runs against both backends
  • Next.js 16
  • React 19

System 02

Webhook platform

your service→ hooklineGo→ hookscopeNode + React

Deliver webhooks reliably, then watch them land live. Flip hookscope to 503 and you can see hookline's retries, backoff and circuit breaker as they happen.

GoCI passing

hookline

Reliable webhook delivery on PostgreSQL, with no Kafka or Redis needed.

  • FOR UPDATE SKIP LOCKED queue with leases: replicas scale out and crashed workers lose nothing
  • Full-jitter retries, Retry-After, dead-letter queue with one-call redelivery
  • Per-endpoint circuit breaker with a single half-open probe; HMAC signing with key rotation
  • Go
  • PostgreSQL
  • Distributed systems
View on GitHub ↗
Node.js + ReactCI passing

hookscope

Live webhook inspector with a zero-dependency Node server.

  • SSE fan-out with Last-Event-ID resume and slow-consumer backpressure
  • Streamed bodies with hard size limits, constant-time signature checks, token-bucket rate limiting
  • React 19 UI on useSyncExternalStore + useDeferredValue, no state library
  • Node.js
  • React 19
  • Server-Sent Events
